# DEV HUB — 開発司令塔

GitHub上の開発中アプリを、iPhoneで見やすく一覧・構成確認するための無料ダッシュボードです。

## 主な機能
- 公開リポジトリを自動取得
- Godot / Web・PWA / その他を自動判定
- 各アプリの説明、主要構成、更新時期を表示
- 進捗状態・進捗率・現在の目的・次の作業・メモを端末内に保存
- 詳細画面で主要ファイル構成を確認
- 任意のGitHub Fine-grained tokenで非公開リポジトリも端末側から取得可能
- PWA対応（iPhoneのホーム画面追加を想定）
